# Bugfix workflow (reference)

The Lead's shorter sequence for bug reports and regressions.

1. `lead.analyze` \u2014 reproduce/understand the bug from the request and repository state.
2. `backend.fix` or `frontend.fix` \u2014 whichever specialist owns the affected area.
3. `qa.verify` \u2014 add a regression test and run verification commands.
4. `lead.review` \u2014 summarize the fix and route to human approval.
